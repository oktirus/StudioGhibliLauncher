Перший стабільний реліз нативного Android TV лаунчера **Ghibli · Вітер над долиною** (`ua.ghibli.tv.valley`).

### Що всередині
- **8 живописних краєвидів Studio Ghibli** (Камфорний ліс, Купальні у сутінках, Луг мандрівного замку, Приморська пекарня, Праліс кедрів, Острів у хмарах, Будинок на скелі, Потяг крізь тишу) з паралаксом, атмосферними частинками й цитатою для кожного краєвиду.
- **20 вільних 2D cel-іконок** у стилі Studio Ghibli 1990-х для популярних TV-застосунків та архіву без квадратних рамок.
- **6 духів навігації:** Сусуватарі (зі стрибками між іконками), Полум’я Кальцифера, Сяйво Кодама, Вітер долини, Кристал Лапути та Паперові птахи.
- **Мінігра «Політ крізь долину»:** 3 ігрові герої (**Сусуватарі**, **Кодама**, **Тоторо**) зі справжнім 4-кадровим чергуванням ніг і рук, безшовною долиною, луговою стежкою, ручно намальованими перешкодами та окремими рекордами.
- **Аудіо:** 3 оригінальні оркестрові мелодії Joe Hisaishi (*Totoro*, *Spirited Away*, *Howl's Moving Castle*) та натуральні звуки духів і мінігри.
- **Керування пультом, Home і автооновлення:** повна D-pad навігація, контекстне меню довгим **OK**, режим спокою «Тиха мить», налаштування домашнього екрана (включно з «Ghibli після Home» для Google TV) та вбудована перевірка релізів GitHub.
